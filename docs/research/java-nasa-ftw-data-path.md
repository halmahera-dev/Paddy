# Java NASA and FTW data path

Checked: 26 September 2026. Test point: 110.4° E, 7.8° S (Yogyakarta area). The test proves that selected endpoints answer small requests; it does not validate the data against Java field records.

## Decision

Use **FTW PMTiles in the browser** for a Java overview. Build a **small server-side pilot subset** of FTW polygons and NASA time series for analysis. Use the public **POWER daily point API** first to prove a full climate-data path. Add IMERG, HLS and SMAP through a batch ingestion job after Earthdata Login and source-specific subsetting are set up. Do not put large GeoParquet, NetCDF, HDF5 or HLS scene files in the browser. These are engineering recommendations based on the access tests and source formats below.

## Small requests tested

1. **POWER:** [daily API request for 1–7 August 2025](https://power.larc.nasa.gov/api/temporal/daily/point?parameters=T2M,ALLSKY_SFC_SW_DWN,PRECTOTCORR&community=AG&longitude=110.4&latitude=-7.8&start=20250801&end=20250807&time-standard=UTC&format=JSON) returned HTTP 200 and 1,030 bytes. It reports T2M = 25.41 °C, solar = 20.23 MJ/m²/day and PRECTOTCORR = 0.31 mm/day on 1 August. The response named SYN1DEG and MERRA2 as sources. This is a working time-series request, not a pilot-area average.
2. **FTW:** HTTP `Range: bytes=0-126` on the [2025 PMTiles archive](https://data.source.coop/ftw/global-field-boundaries/pmtiles/ftw-global-fields-2025.pmtiles) returned **206 Partial Content**, 127 bytes, `Accept-Ranges: bytes`, and `Access-Control-Allow-Origin: *`. The [Indonesia GeoParquet](https://data.source.coop/ftw/global-data/predictions/vectors/alpha/results-by-admin-conf/admin:country_code=ID/Indonesia.parquet) returned **206**, 128 bytes for `Range: bytes=0-127`, with the same range and CORS headers. This supports remote tile reads and server-side Parquet range reads; actual Java tile rendering and bbox query speed still need a pilot test. [FTW catalog](https://source.coop/ftw/global-data)
3. **HLS:** [CMR STAC bbox/date search](https://cmr.earthdata.nasa.gov/stac/LPCLOUD/collections/HLSS30_2.0/items?bbox=110.3,-7.9,110.5,-7.7&datetime=2025-08-01T00:00:00Z/2025-08-07T23:59:59Z&limit=1) returned an S30 item, `HLS.S30.T49MDM.2025217T023551.v2.0`, with protected band COG links. An anonymous 4-byte range request for its B02 band ended in HTTP **401**. Discovery works; data read needs login.
4. **IMERG/SMAP:** Public [CMR IMERG granule search](https://cmr.earthdata.nasa.gov/search/granules.json?short_name=GPM_3IMERGDF&version=07&bounding_box=110.3,-7.9,110.5,-7.7&temporal=2025-08-01T00:00:00Z,2025-08-02T00:00:00Z&page_size=1) found a 1 August 2025 daily NetCDF4 granule and its protected GES DISC and OPeNDAP links. [CMR SMAP granule search](https://cmr.earthdata.nasa.gov/search/granules.json?short_name=SPL4SMGP&version=008&bounding_box=110.3,-7.9,110.5,-7.7&temporal=2025-08-01T00:00:00Z,2025-08-02T00:00:00Z&page_size=1) found a protected HDF5 granule. A [Late-run CMR search](https://cmr.earthdata.nasa.gov/search/granules.json?short_name=GPM_3IMERGDL&version=07&temporal=2026-09-20T00:00:00Z,2026-09-21T00:00:00Z&page_size=1) found a 20 September 2026 V07C granule. No authenticated data download was tested.

## Implementation boundary

Store source, collection/version, run, UTC period, native cell or HLS tile, units, fetch date, and missing-data flags with every derived value. District or pilot-zone summaries can be calculated from source grids, but a 30 m pixel or 9–50 km weather cell does not become an independent field measurement when attached to an FTW polygon. Local field boundaries, crop labels, irrigation and soil observations remain necessary to validate any rotation model. This is an inference from the cited source scales and FTW's predicted-boundary method.
