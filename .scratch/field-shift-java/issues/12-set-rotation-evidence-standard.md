# Set the rotation evidence standard

Type: `grilling`  
Status: resolved  
Parent: [Field Shift Java decision map](../map.md)
Blocked by: 08, 09, 10

## Question

What evidence and review must support a comparison of rotation options before an agency or researcher may use it? Define the baseline against KATAM, treatment of rainfed versus irrigated land, crop and soil rules, uncertainty display, and field checks in the pilot. Decide what the service calls an exploratory scenario and what it may call a recommendation.

## Answer

The first checked pilot is an **agronomist review aid**. It compares two proposed crop sequences for a checked local plot. Staff may use its evidence note before the independent test is complete if the note says **unvalidated**. It does not issue a farmer-facing recommendation. Before the partner data gate passes, an area-level comparison with example plans is an **exploratory scenario**, with no plot advice.

The first evidence check covers **calendar fit and crop water estimates**. It does not claim a yield gain, soil improvement, or future irrigation delivery. Show crop water demand separately from a soil-based water gap and from irrigation feasibility. The latter results need checked local soil and water facts. Keep rainfed and irrigated cases separate; do not transfer a result from one land type to the other.

A named local agronomist approves each local crop-duration, calendar, soil, and water rule before it affects a review result. Record the rule's area, date, source, and reviewer. If no rule or required input is checked, mark only the dependent result unknown. Show source period and scale, data gaps, and plausible ranges. A review note does not prefer one plan when the ranges overlap or a key local fact is missing. It may still state that a plan violates a checked constraint.

Show the dated KATAM guidance for the same *kecamatan* and season beside each plan as a reference. Record agreement or disagreement without a better-than-KATAM claim. When they differ, a local reviewer checks crop duration, land type, water access, and the KATAM version, then records the cause before using the note.

Before examining independent outcomes, the pilot partner and agronomist write a test plan: the held-out plot-seasons, sample size and success limits for each rainfed and irrigated group, field checks, and handling of missing records. Check calendar results against dated local crop events and water calculations against independently recorded weather and water observations where the measured quantity matches the estimate. Report errors and missing coverage by group. A small or incomplete check tests the process; it does not establish performance. The first pilot remains a review aid even after a successful check. A later farmer-facing recommendation needs a separate decision, local rules, independent results, and partner sign-off.

This standard follows the [pilot input contract](./04-pilot-input-contract.md) and [partner data gate](./10-choose-pilot-evidence.md). [KATAM](https://bengkulu.brmp.pertanian.go.id/layanan/layanan-lainnya/katam-terpadu-sc) already gives planting guidance down to *kecamatan* level. [FAO-56](https://www.fao.org/4/X0490E/x0490e0a.htm) defines crop evapotranspiration as an estimate from weather and crop coefficients, so it is not a measure of irrigation delivered to a plot.

The user confirmed this standard.
