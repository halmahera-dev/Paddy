# Test a path to crop history evidence

Type: `research`  
Status: resolved  
Parent: [Field Shift Java decision map](../map.md)

## Question

How can a pilot reconstruct past crop sequences for fields or farming zones on Java? Compare local records with inference from NASA HLS vegetation time series and any other relevant open imagery. State what labels, seasons, cloud handling, field geometry checks, and ground validation would be required to identify rice versus other crops. Decide what a first proof may show as observed, inferred, or unknown.

## Answer

Use dated, plot-linked local records to establish named crops and their sequence. Use NASA HLS time series and Sentinel-1 radar to check cycle timing and infer rice only after pilot validation. BPS KSA and SIMOTANDI can check rice stage or area, but neither public aggregate can name each field's secondary crop. Check geometry, clear HLS pixels, cloud gaps, and held-out fields before any field claim. Label each event **observed**, **inferred**, or **unknown**. Without local records and an independent check sample, limit the first proof to area-level rice timing and uncertain crop-cover cycles. See [the cited research report](../../../docs/research/java-crop-history-method.md).
