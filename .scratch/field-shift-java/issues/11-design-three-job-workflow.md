# Design the three-job workflow

Type: `prototype`  
Status: resolved  
Parent: [Field Shift Java decision map](../map.md)

## Question

What simple workflow lets each main user move from Java-wide risk screening to past crop evidence and then to a rotation comparison for a pilot zone? Make a rough screen or flow that the user can react to. Show where a result points to KATAM, NASA data, and local observations, and what action the user can take at the end.

## Draft for review

[Three-job workflow prototype](../three-job-workflow-prototype.md)

## Answer

The user accepted the [three-job workflow prototype](../three-job-workflow-prototype.md). Maps has three equal modes: area screening, crop history, and rotation comparison. One selected area stays in place across modes, and users can enter any mode without completing another. Each mode links its results to source evidence. Screening ends with an area marked for a local check; comparison ends with an evidence note for agronomist review; researchers can inspect and export the same evidence. KATAM appears as dated comparison context, while NASA estimates and local observations keep their own source, period, coverage, and claim type. Checked plot details appear only after the partner data gate passes. Before that, example plans remain area-level scenarios with clear limits.
